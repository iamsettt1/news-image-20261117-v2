A one-page illustrated newspaper summing up Tuesday 17 November 2026 in a single 1024×1024 image, drawn entirely with original PIL vector artwork. A dominant lead panel shows the Kerch Bridge strike (collapsed span, flames and smoke over the strait), above five large panels — tankers mined at Hormuz, the Xi–Trump–Putin Shenzhen summit, the JPMorgan software-bug outage, the failed Vulcan rocket and its 40 lost satellites, and Estonia closing its Russia border — plus a markets ticker with Nvidia's earnings and an ALSO TODAY line (Japan's jet protest, the Rwanda return hub, the Houthi pipeline strike). The Node program simply copies the finished entry.png to the output directory, byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
